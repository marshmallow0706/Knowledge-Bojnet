## 7.1 利用者（参加先）

日銀ネットの利用者は、日本銀行と当座預金取引や国債振替決済制度の参加関係を持つ金融機関等です。

| 主な利用者の種類 | 例 |
|---|---|
| 預金取扱金融機関 | 都市銀行、地方銀行、信託銀行、外国銀行在日支店、信用金庫（一部） |
| 金融商品取引業者 | 証券会社（国債系・当座預金取引） |
| 短資会社 | コール市場の仲介 |
| 金融市場インフラ（FMI） | 全国銀行資金決済ネットワーク（全銀ネット）、日本証券クリアリング機構（JSCC）、ほふりクリアリング 等 |
| 政府関係 | 国庫金（政府預金）関係事務 |

> 2008年時点で約400先の金融機関等が日銀ネットを利用していたとされます（NTTデータ発表資料）。現在の利用先数は日本銀行の公表資料で確認してください。

## 7.2 法的・制度的基盤

| 項目 | 根拠・規程 |
|---|---|
| 日本銀行の業務 | 日本銀行法（決済の円滑の確保：第1条第2項 等） |
| 当座預金取引 | 当座勘定取引に関する規程・取引先選定基準 |
| 国債振替決済制度 | 社債、株式等の振替に関する法律（社株法）、同法に基づく業務規程 |
| 日銀ネットの利用 | 日銀ネットの利用に関する規程・利用要領（利用先向け） |
| 稼働時間 | 「日銀ネットにおけるオンライン入力開始時刻等に関する件」 |
| 担保 | 適格担保取扱基本要領 等 |

## 7.3 国際基準（FMI原則）への対応

日本銀行は、CPMI-IOSCO の「**金融市場インフラのための原則（PFMI）**」に基づき、自ら運営する日銀ネット（資金決済システム）と国債振替決済制度について **情報開示（自己評価）** を公表しています。主な評価項目は以下です。

- 法的基盤、ガバナンス、包括的リスク管理
- 信用リスク・担保・流動性リスク
- 決済のファイナリティ、マネー決済
- 証券決済システム（DVP）、オペレーショナルリスク
- アクセス・参加要件、階層的参加、効率性、通信手続・標準（ISO 20022 等）、情報開示

## 7.4 利用者との対話の枠組み

- **日銀ネットの有効活用に向けた協議会**（2013年8月設置、事務局：日本銀行決済機構局）
  稼働時間拡大（フェーズⅠ実施済、フェーズⅡ検討）、クロスボーダー円決済、ISO 20022 対応等を議論。
- 協議会の下に WG を設置（例：「円とJGBのグローバルな有効活用WG」「円建て顧客送金・銀行間送金WG」「クロスボーダー決済インフラWG」。2022年にもWG新設・メンバー追加公募）。

## 7.5 料金

日銀ネットの利用には、日本銀行が定める利用料金（基本料金・従量料金等）がかかります。料金体系は日本銀行の公表資料・利用規程で定められています。

## 7.6 運用ガバナンスの要点

1. **変更管理**：電文改訂・稼働時間変更は事前公表、意見募集、接続試験、移行日決定の手順を踏む。
2. **障害対応**：障害時の稼働時間延長、代替手段（端末入力・書面）、関係者への周知。
3. **オーバーサイト**：日本銀行は民間FMIのオーバーサイトも行い、決済システム全体の安全性を確保。
